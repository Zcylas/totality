PLAYER LEVEL SYSTEM
----------------------------------------------------------------
LEVEL CAP: 150 (changed from 100 — confirmed via code: MAX_LEVEL = 150)

XP FORMULA: Skyrim-style exponential
  skillImproveMult × level^1.95 + skillImproveOffset
  (verify multiplier values against UESP wiki, not Skyrimcraft)

PER LEVEL REWARD: +1 ability point to spend freely

DESIGN PHILOSOPHY:
- Players can become genuinely powerful at max level
- Difficulty comes from custom mobs, quests, events
- NOT from artificial stat caps
- Think D&D 5e meets Skyrim meets Hypixel Skyblock

----------------------------------------------------------------
ABILITY SCORES
----------------------------------------------------------------
8 STATS:
- STR (Strength)
- DEX (Dexterity)
- CON (Constitution)
- INT (Intelligence)
- WIS (Wisdom)
- CHA (Charisma)
- FTH (Faith) — custom addition
- END (Endurance) — custom addition (replaces/supplements CON for stamina)

ALL START AT: 10 (modifier 0)

MODIFIER FORMULA: (score - 10) / 2 (standard D&D)

POINT SPENDING:
- NOTE: In code currently +5 per player level (final value not decided yet)
- Spend freely on any stat
- No ability score improvements from class levels
  (class levels give feats ONLY, never ASI)
- Final per-level amount TBD — balance discussion not completed

FUTURE ATTRIBUTE EFFECTS (must be added to StatAttributeApplier.apply()):
- STR → attack damage
- DEX → attack speed
- WIS → XP rate
- CHA → merchant prices
- END → carry weight / stamina pool
- CON → HP pool
- INT → mana pool

----------------------------------------------------------------
RESOURCE FORMULAS (HP / MANA / STAMINA)
----------------------------------------------------------------
HP = base + CON modifier × multiplier
MANA = base + INT modifier × multiplier
STAMINA = base + END modifier × multiplier

DESIGN CONSTRAINT:
- A basic sustained spell (Glide) costs ~500 mana
- A max-level full-INT build (modifier +50) should cast this
  freely and repeatedly — it should feel basic at that level
- Non-INT builds should barely be able to cast at all
- Formulas need balancing to meet this constraint

COMBAT SYSTEM
----------------------------------------------------------------
ATTACK ROLL: d20 + ability modifier + proficiency bonus vs target AC
SAVING THROW: d20 + ability modifier (+ proficiency if class grants it)
  vs spell save DC
DAMAGE: dice-based (Dice enum covers all standard dice)

D20 RESULTS:
- Nat 1: critical failure (animation + negative outcome)
- Nat 20: critical success (always succeeds regardless of DC)
- Advantage: roll two dice, take HIGHER
- Disadvantage: roll two dice, take LOWER

POWER ATTACK:
- Hold attack key for 12 ticks → power attack activates
- Costs stamina
- Grants advantage on attack roll
- Dual wield power attack: both hands attack simultaneously,
  costs double stamina

ARMOR CLASS:
- LIGHT, MEDIUM, HEAVY types
- CLOTHING: transparent to AC (doesn't provide AC)
- UnarmoredDefenseRegistry: Barbarian and Monk register their own formulas
  via UnarmoredDefensePassive (mirrors PhysiologyPassive pattern)

WEAPON STATS:
- VanillaWeaponStats: maps vanilla weapons to Dice + modifier
- TotalityMeleeWeaponItem: custom weapons expose stats via data component
- VanillaDamageInterceptor: d20 mob-to-player vs AC
- CombatResolver: player-to-mob with power attack advantage

MOB STATS:
- MobCombatStats: HP scaling by level + CON modifier
- MobStatsSyncPayload + MobStatsClientCache: sync level/rank/AC/rarity
- MobHealthBarHud: shows level, rank prefix, AC, rarity color

RANK SYSTEM:
- E, F, D, C, B, A, S, Z
- Rank is FIXED per mob type (set in JSON), never rolled mechanically
- SpawnRarity (COMMON→LEGENDARY): rolled on spawn for hostile mobs only
  Non-hostile mobs have no spawn_variants
- Z rank: gods, Warlock patrons, named characters
  (Naruto, Ichigo, Gilmore etc.) — hand-crafted, never randomly spawned

----------------------------------------------------------------
CONDITION: One-handed weapon in mainhand AND offhand simultaneously
BEHAVIOR:
- Left click: right hand attacks (mainhand)
- Right click: left hand attacks (offhand)
- Each hand: independent cooldown
- Power attack (both): simultaneous attack, double stamina cost
- Scissor block (V): crossing swords parry when blocking with dual weapons
- One-handed restriction: only items tagged totality:one_handed can dual wield

DUAL WIELDING SKILL:
- Dedicated skill (planned)
- Higher skill = slightly faster cooldowns

----------------------------------------------------------------
REST SYSTEM
----------------------------------------------------------------
SHORT REST:
- Max 2 per Long Rest (BG3 style)
- shortRestCount tracked in player component
- Resets to 0 on Long Rest
- Triggered via: Rest ability in radial, OR bed interaction choice

SHORT REST EFFECTS:
- Warlock spell slot recovery
- Hit Dice healing
- Attunement processing

LONG REST:
- Full HP restore
- All spell slots restored
- Ability cooldowns reset
- Wizard spell preparation
- Triggered via: bed sleep (Minecraft night mechanic = natural 24hr limit)

ATTUNEMENT:
- Via Short Rest (item in inventory during rest = attuned)
- Drop item = unattuned immediately
- D&D 3-slot cap DROPPED (too restrictive for Minecraft)

SPELL SYSTEM
----------------------------------------------------------------
CANTRIPS (spell level 0):
- No slot cost
- Always castable
- Examples: Eldritch Blast, Firebolt, Ray of Frost, etc.

LEVELED SPELLS (1-10):
- Slot-based
- Slot level gates which spells are available
- Spells are innate to player (not stored in items)
- LearnedSpellsComponent tracks known spells

SPELL COMPONENTS:
- VERBAL
- SOMATIC
- MATERIAL (replaceable or costly)
- Component Pouch: 27-slot container, bypasses material components

IMPLEMENTED SPELLS:
Cantrips: Eldritch Blast, Firebolt, Ray of Frost, Chill Touch,
          Toll the Dead, Poison Spray, Magic Missile (0-level)
Level 1: Mage Armor, Burning Hands, Sleep, Armor of Agathys, Hex, Misty Step
Level 2: Silence, Scorching Ray
Level 3: Lightning Bolt
Level 5: Cone of Cold
Level 6: Disintegrate
Level 7: Crown of Stars

SPELL NOTES:
- Disintegrate: DEX saving throw, success = 0 damage, kill = immediate DUST
- Poison Spray: poison DAMAGE only, does NOT apply Poisoned condition
- Shield, Hellish Rebuke: deferred pending reaction system
- Multi-dice rolls (8d6 Fireball): lightweight HUD notification, not full dice screen

ITEM-GRANTED SPELLS (4th magic category):
- Charge-based magic items grant spells without the player having learned them
- Example: Wand of Fireballs grants Fireball while used
- No class gate — anyone can use a magic item
- NOT added to LearnedSpellsComponent (item manages its own charges)
- References central spell registry for the spell effect
- Lost when charges run out or item is dropped/lost

BLESS (implemented):
- Converted to MobEffect (was flat effect before)
- Visible with icon, duration timer, swirl
