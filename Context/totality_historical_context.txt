MOD IDENTITY & PHILOSOPHY
----------------------------------------------------------------
Mod ID: zcylas.totality
Minecraft: 26.1.2
Loader: Fabric
Mappings: Mojang official

DESIGN INFLUENCES:
- D&D 5e (class system, spell slots, saving throws, dice mechanics)
- Skyrim / Elder Scrolls (skill trees, alchemy, world exploration)
- Baldur's Gate 3 (dice roll screen, advantage/disadvantage, short rest)
- Hypixel Skyblock (bestiary, skill milestones, fishing tiers)
- Solo Leveling, Naruto, Bleach, One Piece, Dragon Ball (power systems)
- Critical Role (named NPCs, patron system, Abyssal Engine lore)
- Ars Nouveau (Grimoire/rune system)
- Tinker's Construct (future casting table system)
- Kenshi (wound system, planned)

CORE PHILOSOPHY:
- Powers interact with the world, scale with RPG stats, feel physical,
  have visual impact, and work for both players AND mobs
- Avoids pure cooldown-damage loops
- D&D-style checks layered on deterministic mechanics
  (Nat 1 failures, Nat 20 crits)
- Data-driven wherever possible (JSON recipes, shop configs, quest defs)

PLAYER DEATH & CORPSE SYSTEM (designed, not yet implemented)
----------------------------------------------------------------
DEATH PIPELINE:
1. HP hits 0 → player FAINTS (lying down animation via PlayerAnimationLibrary)
2. Death saving throws begin (D&D style)
3. 3 failed saves → actually dies
4. CorpseEntity spawns at death location
5. Player respawns naked at spawn point / bed
6. Player gets compass pointer toward their corpse location

CORPSE ENTITY:
- Single entity (not block)
- Stores: original EntityType, UUID, persistent inventory
- Renderer: wraps original mob renderer with 90-degree X rotation (lay flat)
  PoseStack rotation approach (works for vanilla mobs)
  GeckoLib mobs need separate handling eventually
- Decomposition stages (timer-based):

  FRESH (0-5 min):
  Full loot intact
  Resurrectable with Raise Dead, True Resurrection
  Usable in blood rituals

  DECOMPOSING (5-20 min):
  Skin shows decay overlay (or particle effects: flies, green wisps, dust motes)
  Food/perishable items disappear
  Raise Dead no longer works, Animate Dead still does

  SKELETAL (20+ min):
  Only bones and durable items remain
  Only Animate Dead works
  Good for bone meal / ritual sacrifice
  Spontaneous undead reanimation chance (always-on until configs added)

  DUST:
  Despawns entirely
  Creature-specific dust items drop

- Gentle Repose spell: pauses decomposition timers
- Disintegrate: forces immediate DUST stage, skips all stages

ITEMS LOST OVER TIME:
- Food → gone at DECOMPOSING
- Potions → gone or degraded at DECOMPOSING
- Paper/books → gone at SKELETAL
- Armor/weapons/gems → persist to DUST stage

CORPSE ITEMS (carrying corpses):
- CorpseItem: inventory item representing a corpse you're carrying
- STR threshold checks (heavy to carry)
- Nested loot inside

BUTCHERING:
- Animals + dark ritual ingredients
- Planned system

PLAYER ANIMATION LIBRARY:
- MIT licensed, bundled as dependency in Gradle
- Used for: faint collapse animation, cast poses, flight lean,

- Cast animations double as cooldown indicators
- NOT GeckoLib — separate library

ATTUNEMENT:

- Item in inventory during Short Rest = attuned
- Drop item = unattuned
- D&D 3-slot cap DROPPED (too restrictive for Minecraft)
